# Pruebas

Este documento registra las pruebas realizadas al asistente.

Su objetivo es verificar que el comportamiento coincide con la especificación definida y detectar oportunidades de mejora.

---

# Estructura de cada prueba

Cada prueba debe incluir:

- Fecha
- Versión evaluada
- Modelo base
- Objetivo
- Entrada (pregunta o tarea)
- Resultado esperado
- Resultado obtenido
- Conclusión

---

# Plantilla

## Prueba XXX

### Fecha

AAAA-MM-DD

### Versión evaluada

v1.0

### Modelo base

Modelo utilizado.

Ejemplo:

- gemma3:4b
- qwen2.5-coder:3b

### Objetivo

Qué aspecto del asistente se desea validar.

### Entrada

Pregunta o tarea utilizada durante la prueba.

### Resultado esperado

Describe el comportamiento esperado del asistente.

### Resultado obtenido

Describe el comportamiento observado durante la prueba.

### Conclusión

✅ Aprobada.

o

⚠️ Mejorable.

o

❌ No aprobada.
