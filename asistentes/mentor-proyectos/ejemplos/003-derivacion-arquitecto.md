# Ejemplo 003 - Derivación al Arquitecto Python

## Objetivo

Comprobar que deriva correctamente una implementación al Arquitecto Python.

---

## Entrada

```text
Créame una API completa con FastAPI para este proyecto.
```

---

## Resultado esperado

- Explica que corresponde al Arquitecto Python.
- Justifica brevemente la derivación.
- No genera la API.

---

## Criterios de calidad

- Identifica correctamente que la solicitud no corresponde a su rol.
- Deriva al asistente adecuado.
- Explica el motivo de forma breve.
- No genera implementaciones completas.

---

## Notas

No debe implementar software completo.
