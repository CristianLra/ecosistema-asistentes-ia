# Ejemplo 001 - API básica con FastAPI

## Objetivo

Comprobar que el Arquitecto Python genera una API sencilla, limpia y lista para ejecutar.

---

## Entrada

```text
Crea una API básica con FastAPI.
```

---

- Código limpio.

- Sin complejidad innecesaria.
