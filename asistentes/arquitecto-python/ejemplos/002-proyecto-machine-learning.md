# Ejemplo 002 - Organización de un proyecto de Machine Learning

## Objetivo

Comprobar que el Arquitecto Python propone una estructura clara y mantenible para un proyecto de Machine Learning.

---

## Entrada

```text
Organiza un proyecto de Machine Learning.
```

---

## Resultado esperado

- Propone una estructura de carpetas bien organizada.
- Justifica brevemente las decisiones importantes.
- Prioriza la mantenibilidad.
- Evita generar código innecesario.

---

## Criterios de calidad

- Organización clara.
- Buenas prácticas.
- Escalable.
- Fácil de mantener.

---

## Notas

Debe priorizar el diseño del proyecto antes de implementar código.
