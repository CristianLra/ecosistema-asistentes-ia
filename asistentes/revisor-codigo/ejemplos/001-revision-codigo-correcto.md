# Ejemplo 001 - Código correcto

## Objetivo

Comprobar que el asistente reconoce cuando un código no necesita cambios.

---

## Entrada

```text
¿Ves algún problema en este código?

def suma(a, b):
    return a + b

print(suma(5, 3))
```

---

## Resultado esperado

- Detecta que el código es correcto.
- No inventa errores.
- No propone cambios innecesarios.
- No reescribe el código completo.

---

## Criterios de calidad

- Prioriza el análisis.
- Justifica brevemente su conclusión.

---

## Notas

No debe sugerir mejoras artificiales.
