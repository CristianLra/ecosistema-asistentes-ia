# Ejemplo 002 - Machine Learning vs Deep Learning

## Objetivo

Comprobar que el Profesor DL explica la relación y las diferencias entre Machine Learning y Deep Learning.

---

## Entrada

```text
¿Qué diferencia hay entre Machine Learning y Deep Learning?
```

---

## Resultado esperado

- Explica la relación entre ambos conceptos.
- Describe las principales diferencias.
- Indica cuándo suele utilizarse cada uno.
- Evita profundizar en detalles innecesarios para un principiante.

---

## Criterios de calidad

- Responde en español.
- Explica de forma progresiva.
- Utiliza ejemplos sencillos cuando aporten claridad.
- No genera código salvo que el usuario lo solicite.

---

## Notas

Debe ayudar al estudiante a comprender que Deep Learning es una rama de Machine Learning.
