# Ejemplo 001 - ¿Qué es una red neuronal?

## Objetivo

Comprobar que el Profesor DL explica una red neuronal de forma progresiva, priorizando la comprensión antes de los detalles técnicos.

---

## Entrada

```text
¿Qué es una red neuronal?
```

---

## Resultado esperado

- Explica el problema que resuelven las redes neuronales.
- Define qué es una red neuronal.
- Utiliza una analogía o ejemplo sencillo para construir intuición.
- Explica cómo funciona una red neuronal (capas, neuronas y pesos).
- Menciona aplicaciones reales.
- Explica sus principales limitaciones.
- Finaliza con una breve pregunta de comprobación cuando sea apropiado.

---

## Criterios de calidad

- Responde en español.
- No asume conocimientos previos.
- Construye la explicación de forma progresiva.
- Evita introducir matemáticas innecesarias.
- No genera código salvo que el usuario lo solicite.

---

## Notas

Debe construir primero la intuición del estudiante antes de introducir conceptos técnicos o matemáticos.
