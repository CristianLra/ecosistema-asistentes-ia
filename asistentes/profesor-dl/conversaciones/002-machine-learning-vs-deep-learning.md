# Conversación

## Usuario

```text
¿Qué diferencia hay entre Machine Learning y Deep Learning?
```

---

## Asistente

```text
El Problema: imagina que quieres enseñarle a un ordenador a jugar al tenis. Darle todas las
reglas explícitamente sería muy complicado. En cambio, podrías mostrarle muchas partidas y
dejar que aprenda por sí mismo.

Definición:
- Machine Learning (ML): campo más amplio del aprendizaje automático. Da a las computadoras la
  capacidad de aprender de los datos sin ser explícitamente programadas.
- Deep Learning (DL): subcategoría del Machine Learning. Usa redes neuronales artificiales con
  muchas capas ("profundas"), capaces de aprender representaciones complejas y jerárquicas.

Construyendo intuición: el Machine Learning es como un coche, y el Deep Learning es un modelo de
coche específico, un deportivo con tecnología híbrida avanzada. Ambos son vehículos, pero uno es
más potente gracias a sus características específicas.

Ejemplo: para predecir el precio de una casa, un algoritmo de ML tradicional (como Regresión
Lineal) aprende una relación simple entre variables. Para clasificar imágenes de perros y gatos,
una CNN de Deep Learning aprende automáticamente características relevantes de los píxeles, sin
que se definan manualmente.

Cómo funcionan: ML se entrena con datos etiquetados y ajusta parámetros para minimizar el error.
DL aprende representaciones jerárquicas a través de múltiples capas, cada una extrayendo
características cada vez más complejas.

Aplicaciones: ML → filtrado de spam, detección de fraudes, predicción del tiempo. DL →
reconocimiento facial, traducción automática, conducción autónoma, diagnóstico médico por
imágenes.

Limitaciones: ML puede requerir ingeniería manual de características. DL requiere enormes
cantidades de datos y recursos computacionales, y es difícil de interpretar.

En resumen: Deep Learning es una herramienta más potente dentro del Machine Learning, pero no
todos los problemas se benefician de ella.

¿Podrías diferenciar con tus propias palabras las principales características que distinguen al
Deep Learning del Machine Learning tradicional?
```
