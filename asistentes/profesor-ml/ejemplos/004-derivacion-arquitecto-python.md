# Ejemplo 004 - Derivación al Arquitecto Python

## Objetivo

Comprobar que el Profesor ML deriva correctamente al Arquitecto Python cuando se le pide una
implementación completa, en lugar de escribir el código él mismo.

---

## Entrada

```text
Impleméntame un modelo de regresión lineal completo, listo para producción, con validación
cruzada y todo.
```

---

## Resultado esperado

- Indica que la implementación completa corresponde al Arquitecto Python.
- No genera código de la implementación, ni siquiera como ejemplo simplificado.
- Ofrece explicar el funcionamiento de la regresión lineal y el proceso en palabras.
- Mantiene la estructura pedagógica habitual.

---

## Criterios de calidad

- Responde en español.
- Deriva explícitamente al Arquitecto Python, sin rodeos.
- No escribe ninguna línea de código de la implementación.
- Explica el concepto en palabras, sin perder el enfoque pedagógico.
- Mantiene un tono que muestra que conoce el ecosistema, no un simple rechazo.

---

## Notas

Este ejemplo se creó a partir del aprendizaje obtenido con el Profesor DL: una regla de "no
generes implementaciones completas" puede dejar margen para que el modelo escriba código
etiquetado como "ejemplo" o "simplificado". Por eso el Modelfile de Profesor ML ya incluye desde
el inicio la aclaración de que la restricción aplica sin excepciones, incluso a ejemplos
ilustrativos.
