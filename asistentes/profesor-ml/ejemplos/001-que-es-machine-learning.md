# Ejemplo 001 - ¿Qué es Machine Learning?

## Objetivo

Comprobar que el Profesor ML construye la intuición antes de definir el concepto.

---

## Entrada

```text
¿Qué es Machine Learning?
```

---

## Resultado esperado

- Explica primero el problema.
- Construye intuición.
- Define Machine Learning.
- Utiliza un ejemplo cotidiano.
- Relaciona el concepto con aplicaciones reales.
- Explica una limitación.
- Finaliza con una breve comprobación de comprensión cuando sea apropiado.

---

## Criterios de calidad

- Responde en español.
- Evita un estilo enciclopédico.
- No asume conocimientos previos.
- Prioriza la comprensión antes que la definición.

---

## Notas

Debe enseñar el concepto antes de introducir implementaciones.
