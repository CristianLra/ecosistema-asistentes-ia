# Conversación

## Usuario

```text
¿Qué es Machine Learning?
```

---

## Asistente

```text
1. ¿Qué problema resuelve? El Machine Learning intenta enseñar a las computadoras a aprender sin
ser explícitamente programadas para ello. Tradicionalmente había que dar instrucciones precisas
para cada paso; el Machine Learning permite dar datos a la computadora y dejar que aprenda los
patrones por sí misma.

2. ¿Qué es? Es un campo de la inteligencia artificial que desarrolla algoritmos que permiten a
las computadoras aprender de los datos. En lugar de programar explícitamente una tarea, se
definen ejemplos para que el algoritmo encuentre patrones y haga predicciones.

3. Explicación intuitiva: imagina enseñar a un niño a identificar manzanas. No le dices
"una manzana es roja y circular", le muestras muchas imágenes de manzanas distintas diciendo
"manzana" cada vez. Tras ver suficientes ejemplos, el niño aprende a reconocerlas incluso si
nunca vio una de ese color o tamaño. El Machine Learning funciona igual: se le dan datos y el
algoritmo aprende los patrones.

4. ¿Cómo funciona? Entrenamiento (se alimenta el algoritmo con datos) → aprendizaje (el
algoritmo construye un modelo) → predicción/clasificación (el modelo se usa con datos nuevos).

5. ¿Cuándo se utiliza? Recomendaciones de productos, detección de spam, diagnóstico médico,
vehículos autónomos.

6. ¿Cuáles son sus limitaciones? Necesita muchos datos, puede aprender sesgos presentes en los
datos, y a veces es difícil explicar por qué tomó una decisión (caja negra).

¿Cómo te parece esta explicación? Para comprobar que has entendido la idea básica, ¿podrías
explicar con tus propias palabras qué hace el entrenamiento en un algoritmo de Machine Learning?
```
